# 💳 บัตรของฉัน — รวมบัตรเครดิตทุกธนาคาร + แจ้งเตือนชำระ (PWA)

แอปมือถือ (ติดตั้งจากเว็บได้ทั้ง Android/iPhone) สำหรับดูภาพรวมบัตรเครดิต / บัตรผ่อนทุกใบในที่เดียว

**รองรับ:** KTC · กสิกรไทย · SCB / CardX · UOB · ttb · กรุงเทพ · ShopeePay SPayLater · HomePro · Central · Lazada · อื่นๆ

## การแจ้งเตือน (เลือกได้ 3 แบบ ใช้ร่วมกันได้)
1. **แจ้งเตือนในแอป** — เตือนเมื่อเปิดแอป (ค่าเริ่มต้น 5, 3, 1 วันก่อน และวันครบกำหนด, เลยกำหนดเตือนทุกวัน)
2. **ปฏิทินมือถือ** — ตั้งค่า > ดาวน์โหลดไฟล์ปฏิทิน แล้วเปิดด้วย Google Calendar / ปฏิทิน iPhone (เตือน 3 วันและ 1 วันก่อน 09:00) *ไม่ต้องเปิดแอปก็เตือน*
3. **อีเมล / LINE ทุกเช้า 08:00** — ผ่าน Google Apps Script ของคุณเอง (`Code.gs`)

### ติดตั้ง Apps Script (ข้อ 3)
1. ไปที่ https://script.google.com > **New project** > วางโค้ดจาก `Code.gs` > บันทึก
2. เลือกฟังก์ชัน **`setup`** > **Run** > อนุญาตสิทธิ์ > เปิด **Execution log** คัดลอก `SYNC_KEY`
3. **Deploy > New deployment > Web app** — Execute as: **Me**, Who has access: **Anyone** > Deploy > คัดลอก URL ที่ลงท้าย `/exec`
4. ในแอป: ตั้งค่า > วาง URL และ SYNC_KEY > **บันทึก & ซิงก์** > **ส่งข้อความทดสอบ**
5. (ไม่บังคับ) ส่งเข้า LINE: สร้าง Messaging API channel ใน LINE Developers แล้วเพิ่ม Script properties `LINE_TOKEN` (Channel access token) และ `LINE_TO` (Your user ID) — แอดบอตเป็นเพื่อนก่อน

> ข้อมูลที่ส่งไป Apps Script มีแค่ ชื่อบัตร, 4 หลักท้าย, วันที่ และยอดบิล — แอปซิงก์ให้อัตโนมัติทุกครั้งที่แก้ไข และวันละครั้งเมื่อเปิดแอป

## นำขึ้น GitHub Pages
1. Settings > Pages > Source: **Deploy from a branch** > Branch: `main` / `(root)` > Save
2. รอประมาณ 1 นาที
3. เปิดลิงก์ https://zolerox.github.io/MyCreditCards/ บนมือถือ > **ติดตั้งแอป / เพิ่มไปยังหน้าจอโฮม**
4. เปิดแอป > **กู้คืนข้อมูลจากไฟล์สำรอง** (ถ้ามี) หรือ **+ เพิ่มบัตร** แล้วตั้ง **วันตัดรอบ** และ **วันครบกำหนดชำระ** (ดูจากใบแจ้งยอด)

## ความเป็นส่วนตัว
- ข้อมูลทั้งหมดเก็บใน **เครื่องของคุณ** (localStorage) ไม่มีเซิร์ฟเวอร์กลาง
- ไม่เก็บเลขบัตรเต็ม, CVV, รหัสผ่านธนาคาร — เก็บแค่ 4 หลักท้าย
- ควรกด “สำรองข้อมูล” เป็นระยะ (ล้างข้อมูลเบราว์เซอร์ = ข้อมูลหาย)


### repo นี้เป็น Public
- **ไม่มีข้อมูลบัตร/ยอดใช้จ่ายของใครอยู่ในโค้ด** — ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของมือถือแต่ละเครื่องเท่านั้น
- ย้ายข้อมูลเข้าเครื่องด้วยไฟล์สำรอง (.json): หน้าแรก > **กู้คืนข้อมูลจากไฟล์สำรอง** หรือ ตั้งค่า > กู้คืนข้อมูล
- **อย่าอัปโหลดไฟล์สำรองขึ้น repo นี้**
